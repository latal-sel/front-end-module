# Module Front-End

Ce repository contient le code source du module front-end de l'application M2. Il est développé en [TypeScript](typescriptlang.org) en utilisant le framework [React](react.dev) avec [Vite](vite.dev) comme outil de build.

## Prérequis

- [Node.js](https://nodejs.org/) (version 14 ou supérieure)
- [npm](https://www.npmjs.com/) (inclus avec Node.js) ou [Yarn](https://yarnpkg.com/)

## Installation

Premièrement, il est nécessaire de cloner le repository :

```bash
git clone https://github.com/latal-sel/front-end-module.git
cd front-end-module
```
Ensuite, installez les dépendances avec npm ou yarn :

```bash
npm install
# ou
yarn install
```
## Démarrage du serveur de développement
Pour lancer le serveur de développement, utilisez la commande suivante :

```bash
npm run dev
# ou
yarn dev
```
Le serveur sera accessible à l'adresse [http://localhost:5173](http://localhost:5173) par défaut.
